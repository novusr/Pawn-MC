theme
=====

Definisi visual PawnMC: skema warna Material 3, tipografi, bentuk, dan beberapa
pembungkus latar yang dipakai bersama.

English
-------

PawnMC's visual definitions: the Material 3 colour schemes, typography, shapes,
and a few shared background wrappers.

Berkas
------

``Color.kt``
    Konstanta warna mentah, termasuk ``status_success`` / ``status_error`` dan
    warna aksen yang dipakai chip status dan marker ``[cause]``.

``Theme.kt``
    ``PawnMCTheme`` - memilih skema terang/gelap dari ``ContentConfig.n_app_theme``.

``Type.kt``
    Skala tipografi.

``DarkSectionContainer.kt``
    Wadah latar gelap untuk kartu output dan sorotan pengaturan.
