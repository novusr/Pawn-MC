PocketSAMP Help Guide
=====================

This guide introduces the main PocketSAMP interface and explains how to set up and manage a server. Each section covers one part of the application, so first-time users can become familiar with the available features step by step.

Panduan PocketSAMP
-----------------

Panduan singkat untuk menyiapkan dan menggunakan PocketSAMP. Ikuti setiap bagian untuk mengenal fungsi utama aplikasi dan memahami cara mengelola server.

.. contents:: Daftar Isi
   :local:
   :depth: 2

Antarmuka Utama
---------------

**Indonesia**

Di halaman utama, Anda dapat memulai atau menghentikan server. Tersedia dua alamat yang bisa digunakan untuk terhubung ke server:

* **Local:** Gunakan alamat ini untuk bermain melalui perangkat yang sama.
* **LAN:** Gunakan alamat ini agar pemain lain di jaringan Wi-Fi atau hotspot yang sama dapat terhubung.

Ketuk salah satu alamat untuk menyalinnya.

Tombol **Start/Stop** berada di bagian bawah dan digunakan untuk menjalankan atau menghentikan server.

Jika ``server.cfg`` belum tersedia, PocketSAMP akan membuatnya menggunakan pengaturan awal ketika server pertama kali dijalankan. Pengaturan bawaan runner meliputi:

* Hostname: ``PocketSAMP/PawnMC Runner``
* Port: ``7777``
* Max Players: ``20``
* RCON Password: ``rcon234``

**English (US)**

The main interface is where you start or stop the server. It provides two addresses for connecting to your server:

* **Local:** Use this address to play on the same device.
* **LAN:** Use this address to let other players on the same Wi-Fi or hotspot network connect.

Tap either address to copy it.

The **Start/Stop** button is located at the bottom of the screen and controls the server.

If ``server.cfg`` does not exist, PocketSAMP creates it with the default runner settings when the server starts for the first time:

* Hostname: ``PocketSAMP/PawnMC Runner``
* Port: ``7777``
* Max Players: ``20``
* RCON Password: ``rcon234``

**Tagalog**

Dito mo sisimulan o ihihinto ang server. May dalawang address na puwede mong gamitin:

* **Local:** Para maglaro gamit ang mismong device na ito.
* **LAN:** Para makakonekta ang ibang players na nasa parehong Wi-Fi o hotspot network.

I-tap ang alinman sa mga address para makopya ito.

Nasa ibabang bahagi ng screen ang **Start/Stop** button. Gamitin ito para simulan o ihinto ang server.

Kung wala pang ``server.cfg``, awtomatikong gagawa ang PocketSAMP ng file gamit ang default runner settings sa unang pagsisimula:

* Hostname: ``PocketSAMP/PawnMC Runner``
* Port: ``7777``
* Max Players: ``20``
* RCON Password: ``rcon234``

**Español**

Aquí puedes iniciar o detener el servidor. La pantalla muestra dos direcciones para conectarte:

* **Local:** Utiliza esta dirección para jugar desde el mismo dispositivo.
* **LAN:** Utiliza esta dirección para permitir que otros jugadores de la misma red Wi-Fi o hotspot se conecten.

Toca cualquiera de las direcciones para copiarla.

El botón **Start/Stop** está en la parte inferior de la pantalla y permite iniciar o detener el servidor.

Si todavía no existe ``server.cfg``, PocketSAMP lo creará con los valores predeterminados del runner durante el primer inicio:

* Hostname: ``PocketSAMP/PawnMC Runner``
* Port: ``7777``
* Max Players: ``20``
* RCON Password: ``rcon234``

**Русский**

Здесь можно запустить или остановить сервер. На главном экране доступны два адреса для подключения:

* **Local:** Используйте этот адрес для игры на том же устройстве.
* **LAN:** Используйте этот адрес, чтобы другие игроки из той же сети Wi-Fi или hotspot могли подключиться к серверу.

Нажмите на любой адрес, чтобы скопировать его.

Кнопка **Start/Stop** находится в нижней части экрана и отвечает за запуск и остановку сервера.

Если файл ``server.cfg`` отсутствует, PocketSAMP создаст его с настройками runner по умолчанию при первом запуске:

* Hostname: ``PocketSAMP/PawnMC Runner``
* Port: ``7777``
* Max Players: ``20``
* RCON Password: ``rcon234``

Console
-------

**Indonesia**

Halaman Console menampilkan pesan yang dihasilkan server selama proses berjalan, termasuk:

* Pesan startup ketika server dimulai.
* Informasi plugin yang berhasil dimuat.
* Pesan error ketika plugin atau gamemode gagal dimuat.

Jika server mengalami masalah, periksa bagian ini terlebih dahulu. Pesan berwarna merah biasanya menunjukkan bagian yang perlu diperhatikan.

Anda dapat membersihkan tampilan Console tanpa menghapus log yang sudah tersimpan di perangkat.

**English (US)**

The Console displays messages generated by the server while it is running, including:

* Startup messages when the server launches.
* Information about successfully loaded plugins.
* Errors when a plugin or gamemode fails to load.

If something goes wrong, check the Console first. Red messages usually indicate an issue that needs attention.

You can clear the Console view without deleting logs saved on your device.

**Tagalog**

Dito makikita ang mga mensaheng inilalabas ng server habang tumatakbo ito, kabilang ang:

* Mga startup message kapag nagsisimula ang server.
* Impormasyon tungkol sa mga plugin na na-load.
* Mga error kapag hindi na-load ang plugin o gamemode.

Kapag may problema, dito ka muna tumingin. Karaniwang ipinapakita ng mga pulang mensahe kung saan nanggagaling ang error.

Puwede mong i-clear ang Console view nang hindi binubura ang mga log na naka-save sa device.

**Español**

La sección Console muestra los mensajes generados por el servidor mientras está en ejecución, incluidos:

* Los mensajes de inicio del servidor.
* La información de los plugins cargados correctamente.
* Los errores cuando un plugin o gamemode no consigue cargarse.

Si ocurre algún problema, revisa primero esta sección. Los mensajes en rojo suelen señalar el origen del problema.

Puedes limpiar la vista de Console sin eliminar los registros guardados en el dispositivo.

**Русский**

В разделе Console отображаются сообщения сервера во время работы, включая:

* Сообщения при запуске сервера.
* Информацию об успешно загруженных плагинах.
* Ошибки, возникающие при загрузке плагинов или gamemode.

Если возникла проблема, сначала проверьте Console. Красные сообщения обычно указывают на причину ошибки.

Очистка отображения Console не удаляет журналы, сохранённые на устройстве.

File Manager
------------

**Indonesia**

File Manager digunakan untuk mengelola file dan folder server.

Folder dapat dibuka dan ditutup langsung dari daftar, sehingga Anda bisa melihat isi subfolder tanpa harus berpindah ke halaman lain.

Untuk membuat file atau folder baru:

1. Pilih folder tujuan terlebih dahulu.
2. Buat file atau folder baru di dalam folder tersebut.
3. Jika tidak ada folder yang dipilih, item baru akan dibuat di folder yang sedang terbuka.

Tersedia dua cara untuk membuka file atau folder melalui editor:

* **Edit:** Membuka file secara langsung di Xed Editor.
* **Open workspace:** Membuka folder sebagai workspace di Xed Editor.

**English (US)**

File Manager lets you manage server files and folders.

Folders can be expanded and collapsed directly in the file list, allowing you to browse nested contents without navigating to another screen.

To create a new file or folder:

1. Select the destination folder first.
2. Create the new file or folder inside it.
3. If no folder is selected, the new item is created in the currently open folder.

You can open files and folders in the editor in two ways:

* **Edit:** Opens the selected file directly in Xed Editor.
* **Open workspace:** Opens the selected folder as a workspace in Xed Editor.

**Tagalog**

Ginagamit ang File Manager para ayusin ang mga file at folder ng server.

Puwedeng buksan at isara ang mga folder direkta sa listahan. Makikita mo agad ang laman ng mga subfolder nang hindi na kailangang lumipat sa ibang screen.

Para gumawa ng bagong file o folder:

1. Piliin muna ang folder na paglalagyan nito.
2. Gumawa ng bagong file o folder sa loob nito.
3. Kung walang napiling folder, sa kasalukuyang bukas na folder ito gagawin.

May dalawang paraan para buksan ang mga file at folder sa editor:

* **Edit:** Direktang binubuksan ang napiling file sa Xed Editor.
* **Open workspace:** Binubuksan ang napiling folder bilang workspace sa Xed Editor.

**Español**

File Manager permite administrar los archivos y carpetas del servidor.

Puedes expandir y contraer las carpetas directamente desde la lista para consultar su contenido sin tener que cambiar de pantalla.

Para crear un archivo o una carpeta:

1. Selecciona primero la carpeta de destino.
2. Crea el nuevo archivo o carpeta dentro de ella.
3. Si no seleccionas ninguna carpeta, el nuevo elemento se creará en la carpeta que esté abierta actualmente.

Hay dos formas de abrir archivos y carpetas en el editor:

* **Edit:** Abre directamente el archivo seleccionado en Xed Editor.
* **Open workspace:** Abre la carpeta seleccionada como un workspace en Xed Editor.

**Русский**

File Manager предназначен для управления файлами и папками сервера.

Папки можно раскрывать и сворачивать прямо в списке, просматривая вложенное содержимое без перехода на другой экран.

Чтобы создать файл или папку:

1. Сначала выберите папку назначения.
2. Создайте новый файл или папку внутри неё.
3. Если папка не выбрана, новый элемент будет создан в текущей открытой папке.

Открыть файлы и папки в редакторе можно двумя способами:

* **Edit:** Открывает выбранный файл непосредственно в Xed Editor.
* **Open workspace:** Открывает выбранную папку как workspace в Xed Editor.

Database
--------

**Indonesia**

PocketSAMP menjalankan MariaDB bersama server. Melalui halaman Database, Anda dapat:

* Membuat database baru.
* Melihat tabel dalam database.
* Menjalankan perintah SQL.
* Mengimpor file ``.sql``.

Akun bawaan yang umum digunakan adalah ``root`` tanpa password. Sesuaikan akun dan kredensial database jika gamemode yang digunakan memerlukan konfigurasi berbeda.

**English (US)**

PocketSAMP runs MariaDB alongside the server. The Database section lets you:

* Create databases.
* View database tables.
* Execute SQL statements.
* Import ``.sql`` files.

The usual default account is ``root`` with no password. Adjust the database account and credentials if your gamemode requires different settings.

**Tagalog**

Kasabay ng server na tumatakbo ang MariaDB. Sa Database section, puwede mong:

* Gumawa ng bagong database.
* Tingnan ang mga table.
* Magpatakbo ng SQL commands.
* Mag-import ng mga ``.sql`` file.

Karaniwang default account ang ``root`` na walang password. Palitan ang account at credentials kung iba ang kailangan ng gamemode mo.

**Español**

PocketSAMP ejecuta MariaDB junto con el servidor. Desde la sección Database puedes:

* Crear bases de datos.
* Consultar las tablas.
* Ejecutar instrucciones SQL.
* Importar archivos ``.sql``.

La cuenta predeterminada habitual es ``root`` sin contraseña. Ajusta la cuenta y las credenciales si tu gamemode necesita una configuración diferente.

**Русский**

PocketSAMP запускает MariaDB вместе с сервером. В разделе Database можно:

* Создавать базы данных.
* Просматривать таблицы.
* Выполнять SQL-запросы.
* Импортировать файлы ``.sql``.

Обычно по умолчанию используется учётная запись ``root`` без пароля. Измените учётную запись и параметры доступа, если ваш gamemode требует другую конфигурацию.

Crash Logs
----------

**Indonesia**

Halaman Crash Logs menyimpan laporan ketika aplikasi berhenti secara tiba-tiba.

Anda dapat membuka detail laporan untuk melihat informasi lebih lanjut, menyalin bagian yang diperlukan, lalu mengirimkannya kepada developer untuk membantu proses pemeriksaan masalah.

Laporan lama juga dapat dihapus agar daftar tetap rapi.

**English (US)**

Crash Logs stores reports generated when the application stops unexpectedly.

You can open a report to inspect its details, copy the relevant information, and send it to the developer to help investigate the issue.

Old reports can also be deleted to keep the list organized.

**Tagalog**

Dito naka-save ang mga report kapag biglang huminto ang application.

Puwede mong buksan ang report para makita ang detalye, kopyahin ang mahahalagang impormasyon, at ipadala ito sa developer para makatulong sa paghanap ng problema.

Puwede ring burahin ang mga lumang report para manatiling maayos ang listahan.

**Español**

Crash Logs almacena los informes generados cuando la aplicación se cierra inesperadamente.

Puedes abrir un informe para consultar sus detalles, copiar la información importante y enviarla al desarrollador para facilitar la investigación del problema.

También puedes eliminar los informes antiguos para mantener la lista organizada.

**Русский**

В Crash Logs сохраняются отчёты, созданные при неожиданном завершении приложения.

Вы можете открыть отчёт, изучить подробности, скопировать важную информацию и отправить её разработчику для анализа проблемы.

Старые отчёты также можно удалить, чтобы список оставался упорядоченным.

Configuration
-------------

**Indonesia**

Halaman Configuration digunakan untuk mengedit pengaturan ``server.cfg``, termasuk:

* **Hostname:** Nama server yang ditampilkan kepada pemain.
* **Port:** Port yang digunakan server.
* **Max Players:** Batas maksimum pemain.
* **RCON Password:** Password untuk akses RCON.
* **Gamemode:** Gamemode yang dijalankan server.
* **Filterscripts:** Daftar filterscript yang dimuat.
* **Plugins:** Daftar plugin yang digunakan server.

Jika ``server.cfg`` belum tersedia, halaman ini akan menampilkan nilai bawaan dari runner.

Tekan **Save** untuk menyimpan konfigurasi ke dalam folder server dan memperbarui ``server.cfg``.

**English (US)**

The Configuration section lets you edit ``server.cfg`` settings, including:

* **Hostname:** The server name displayed to players.
* **Port:** The port used by the server.
* **Max Players:** The maximum number of players allowed.
* **RCON Password:** The password used for RCON access.
* **Gamemode:** The gamemode loaded by the server.
* **Filterscripts:** The list of filterscripts to load.
* **Plugins:** The plugins used by the server.

If ``server.cfg`` does not exist, this section displays the runner's default values.

Press **Save** to write the configuration to the server folder and update ``server.cfg``.

**Tagalog**

Ginagamit ang Configuration para i-edit ang mga setting ng ``server.cfg``, kabilang ang:

* **Hostname:** Pangalan ng server na makikita ng mga player.
* **Port:** Port na ginagamit ng server.
* **Max Players:** Pinakamaraming player na puwedeng kumonekta.
* **RCON Password:** Password para sa RCON access.
* **Gamemode:** Gamemode na tatakbo sa server.
* **Filterscripts:** Listahan ng mga filterscript na ilo-load.
* **Plugins:** Mga plugin na gagamitin ng server.

Kung wala pang ``server.cfg``, ipapakita rito ang default values ng runner.

Pindutin ang **Save** para isulat ang configuration sa server folder at i-update ang ``server.cfg``.

**Español**

La sección Configuration permite editar los parámetros de ``server.cfg``, incluidos:

* **Hostname:** Nombre del servidor que ven los jugadores.
* **Port:** Puerto utilizado por el servidor.
* **Max Players:** Número máximo de jugadores permitidos.
* **RCON Password:** Contraseña para acceder mediante RCON.
* **Gamemode:** Gamemode que ejecutará el servidor.
* **Filterscripts:** Lista de filterscripts que se cargarán.
* **Plugins:** Plugins utilizados por el servidor.

Si ``server.cfg`` todavía no existe, esta sección muestra los valores predeterminados del runner.

Pulsa **Save** para guardar la configuración en la carpeta del servidor y actualizar ``server.cfg``.

**Русский**

В разделе Configuration можно изменять параметры ``server.cfg``, включая:

* **Hostname:** Имя сервера, отображаемое игрокам.
* **Port:** Порт, используемый сервером.
* **Max Players:** Максимальное количество игроков.
* **RCON Password:** Пароль для доступа через RCON.
* **Gamemode:** Gamemode, запускаемый сервером.
* **Filterscripts:** Список загружаемых filterscripts.
* **Plugins:** Плагины, используемые сервером.

Если ``server.cfg`` отсутствует, в этом разделе отображаются стандартные значения runner.

Нажмите **Save**, чтобы записать конфигурацию в папку сервера и обновить ``server.cfg``.

Troubleshooting
---------------

**Indonesia**

Jika server mengalami masalah atau tidak berjalan sebagaimana mestinya, periksa pesan yang ditampilkan di Console terlebih dahulu.

Pesan startup, kegagalan pemuatan plugin, dan error gamemode biasanya memberikan informasi yang diperlukan untuk mengetahui penyebab masalah.

Jika aplikasi berhenti secara tiba-tiba, periksa Crash Logs untuk mendapatkan laporan yang dapat dibagikan kepada developer.

**English (US)**

If the server encounters a problem or does not behave as expected, check the Console messages first.

Startup output, plugin loading failures, and gamemode errors usually provide useful information for identifying the cause.

If the application stops unexpectedly, check Crash Logs for a report that you can share with the developer.

**Tagalog**

Kung may problema ang server o hindi ito gumagana gaya ng inaasahan, tingnan muna ang mga mensahe sa Console.

Karaniwang makikita sa startup output, plugin loading failures, at gamemode errors ang impormasyong kailangan para malaman ang sanhi ng problema.

Kung biglang huminto ang application, tingnan ang Crash Logs at ipadala ang report sa developer kung kinakailangan.

**Español**

Si el servidor presenta algún problema o no funciona como debería, revisa primero los mensajes de Console.

Los mensajes de inicio, los errores al cargar plugins y los problemas del gamemode suelen proporcionar información útil para identificar la causa.

Si la aplicación se cierra inesperadamente, consulta Crash Logs para obtener un informe que puedas compartir con el desarrollador.

**Русский**

Если сервер работает неправильно или возникла ошибка, сначала проверьте сообщения в Console.

Вывод запуска, ошибки загрузки плагинов и сообщения gamemode обычно содержат информацию, необходимую для определения причины проблемы.

Если приложение неожиданно завершилось, откройте Crash Logs и при необходимости отправьте отчёт разработчику.

Final Notes
-----------

**Indonesia**

PocketSAMP menyediakan beberapa halaman untuk mengelola server, file, database, dan konfigurasi dalam satu aplikasi. Jika Anda baru pertama kali menggunakannya, pelajari setiap bagian secara bertahap.

Jika masih mengalami masalah, periksa pesan di Console terlebih dahulu. Untuk masalah yang menyebabkan aplikasi berhenti mendadak, gunakan laporan di Crash Logs.

**English (US)**

PocketSAMP brings server management, file management, database tools, and configuration into one application. If you are new to the app, take some time to explore each section.

If you run into a problem, check the Console messages first. For unexpected application shutdowns, refer to the reports in Crash Logs.

**Tagalog**

Pinagsasama ng PocketSAMP ang server management, file management, database tools, at configuration sa iisang application. Kung bago ka pa lang dito, dahan-dahan mong kilalanin ang bawat section.

Kapag may problema, tingnan muna ang Console. Kung biglang nagsara ang application, hanapin ang report sa Crash Logs.

**Español**

PocketSAMP reúne la administración del servidor, la gestión de archivos, las herramientas de base de datos y la configuración en una sola aplicación. Si acabas de empezar a utilizarla, explora cada sección poco a poco.

Si encuentras algún problema, revisa primero los mensajes de Console. Si la aplicación se cierra inesperadamente, consulta los informes de Crash Logs.

**Русский**

PocketSAMP объединяет управление сервером, файлами, базами данных и конфигурацией в одном приложении. Если вы только начинаете пользоваться приложением, изучайте каждый раздел постепенно.

При возникновении проблем сначала проверьте сообщения в Console. Если приложение неожиданно завершилось, воспользуйтесь отчётами в Crash Logs.
